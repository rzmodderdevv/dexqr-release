# DexQR

**Scan. Create. Share.**

DexQR is an Android QR code and barcode utility built to make everyday
scanning and QR creation straightforward. It brings camera scanning,
gallery scanning, batch scanning, QR generation, scan history, and
link-safety indicators together in one focused app.

> **Developer:** Rezz.DVS\
> **Application ID:** `com.dexqr.rezzdvs`\

------------------------------------------------------------------------

## Features

### Scan QR codes and barcodes

-   Scan codes using the device camera.
-   Choose an image from the gallery and scan codes from it.
-   Support for QR codes and common barcode formats, including Code 128
    and EAN-13.
-   View decoded content on a dedicated result screen.
-   Copy scan results and take the relevant action, such as opening a
    link.

### Batch Scan

Scan multiple codes in one session instead of handling them one at a
time. Batch mode is designed for situations where several QR codes or
barcodes need to be collected quickly.

### QR Code Generator

Create QR codes for six content types: - URL - Text - Phone number -
Email - Wi-Fi - Contact

### QR Customization

Personalize generated QR codes with options including: - Foreground and
background colors. - Preset colors and custom color values. - Different
QR corner and module styles. - PNG export at the available output sizes:
**512 × 512**, **1024 × 1024**, and **2048 × 2048** pixels.

### Link Safety Check

For scanned URLs, DexQR displays basic checks and indicators to help
users assess a link before opening it. These checks are performed
on-device and are not a guarantee that a website is safe.

The current checks may include URL format validation and whether HTTPS
is used. Redirect destinations and website reputation are not verified
by this local check.

### Scan History

-   Keep a record of previous scans on the device.
-   Search and filter scan history by content type.
-   Copy individual results or remove entries.
-   Clear the stored history from Settings.

### Share to DexQR

Open supported shared content in DexQR to continue scanning or working
with it inside the app.

### Themes and Interface

-   Modern, minimal interface using DexQR's blue and navy visual
    identity.
-   System Default, Light, and Dark appearance options.
-   Theme preference is saved locally and persists between app launches.

## Privacy

DexQR is designed around on-device use for its core scanning and history
workflows.

-   Scan history is stored locally on the device.
-   Gallery access is limited to images selected by the user through the
    system photo picker.
-   The link-safety check described above is a local, basic inspection;
    it does not establish a website's reputation or guarantee safety.

Please review the in-app **Privacy Policy** for the complete and current
details of data handling and any third-party services.

## Ads

Some user-facing actions may display rewarded ads. For example, PNG
export in the user build can require completion of a rewarded ad when an
ad is successfully available. If an ad is unavailable, the app uses its
configured fallback behavior.

The admin build bypasses ads.
